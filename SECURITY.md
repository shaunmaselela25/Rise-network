# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/shaunmaselela25/Rise-network/security/advisories/new>).

Include a description, steps to reproduce, the affected area, and potential impact. Do not
access, modify or delete other people's data while testing.

We aim to acknowledge reports within 5 working days. This is a goal, not a guarantee — the
project is maintained by a small team.

> **Maintainer action required:** private vulnerability reporting must be enabled in the
> repository settings (Settings → Code security → Private vulnerability reporting) for the
> link above to work. An official security contact email will be added once decision D-09
> is made.

## Supported versions

The project is pre-release. Only the latest commit on `main` is supported.
